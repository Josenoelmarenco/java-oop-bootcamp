# Java OOP Refresh — Bootcamp

Fuente única de verdad del refresco de Java basado en el repo de Vesa Ollikainen.
Espejo en Notion (mismo contenido) para consulta cruzada con otros LLMs.

Repo de referencia: https://github.com/vesavvo/Object-Oriented-Programming

---

## Cómo funciona

- 8 unidades. Cada unidad = lista cerrada de ejercicios cortos.
- **Sin fechas.** Avanzas a tu ritmo.
- Regla única de avance: **no abres una unidad nueva hasta cerrar todos los ejercicios de la actual.**
- Ritmo mínimo viable: 1 ejercicio/día.
- Ritmo objetivo: 2-3 ejercicios/día.
- Si un día rindes más, avanza. Si rindes menos, ya cumpliste con el mínimo.

## Reglas de repaso (memoria muscular)

1. **Daily log:** al final de cada día, 2-3 líneas en el README de la unidad: qué hiciste, qué te costó, concepto clave.
2. **Cheatsheet por unidad:** al cerrar una unidad, crear `_CHEATSHEET.md` escrito a mano con los patrones sintácticos clave.
3. **Reto sábado (30 min):** elegir un ejercicio aleatorio de una unidad ya cerrada y reescribirlo desde cero sin mirar el original. Comparar después.

## Filosofía

- Leer poco, codificar mucho (30/70 a favor del código).
- Repetición intencional: conceptos centrales reaparecen en varias unidades.
- Un ejercicio = un archivo Java compilable y ejecutable. Si no compila, no cuenta.
- No tratar Java como ejercicio aislado. Aplicar lo que vas aprendiendo a `Inventary_Store` y a otros proyectos reales.
